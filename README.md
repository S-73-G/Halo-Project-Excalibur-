# Halo-Project-Excalibur-
A decompile project for Halo's prerelease builds to lead up to a true decompiling of Halo CE

The order of which the project goes is as follows:
- Speartest/ Macworld 1999
- E3 2000
- 1749 Beta
- 2247 Beta
- Halo CE

Speartest & E3 contain numerous debug asserts and thousands of strings that survived, lots of them have either to do with a function, asserts, or names relating to tag data.
The text file labeled "string_dump" is a direct dump with the address location in Ghidra of the strings.

If you have anything to add for this decomp, please be sure to go to the discord where the process is publicly documented, resources & credit appended, and also serves as the location as to where I'll be able
to see if volunteers wish to help with decompiling.
